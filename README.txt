Название: Симуляция игры «Мафия» для анализа социальной динамики LLM / Mafia Simulation for LLM Social Dynamics Analysis

Стек: Python, OpenAI API, Pandas, Matplotlib, JSON

Что делает: Автоматизирует проведение игры «Мафия» между пятью LLM в роли «мирных». Проводит игру с обнулением памяти, собирает данные по голосованиям, изгнаниям и оценкам доверия.

Структура проекта:

game/
├── token.txt                  # API-ключ (не включается в репозиторий)
├── trust_before.py            # Первичная оценка доверия
├── round1_speech.py           # Речь в первом раунде
├── round1_vote.py             # Голосование в первом раунде
├── round2_speech.py           # Речь во втором раунде
├── round2_vote.py             # Голосование во втором раунде
├── final_evaluation.py        # Финальная оценка партнёра
├── game_runner.py             # Оркестратор: запускает все этапы
└── results/                   # Результаты по каждой игре
    ├── game_1/
    ├── game_2/
    └── ...
